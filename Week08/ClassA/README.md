# Week 08 Class A: useReducer counter

The counter starts at 10. Use **+1** and **-1**, or enter a number and select **Add it**. The reducer keeps `count` and `valueToAdd` in one state object. Each button or input change dispatches an action; the `switch` in `CounterPage.jsx` computes the next state.

To run it:

```bash
cd Week08/ClassA
npm install
npm run dev
```
